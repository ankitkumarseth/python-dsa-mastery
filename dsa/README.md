# DSA Mastery

An interactive, Test-Driven Development (TDD) approach to mastering the NeetCode 150 Core Data Structures and Algorithms.

## How to Use This Repo
1. Read the theory and mental models in `dsa_master_curriculum.md`.
2. Open the stub files in `src/`.
3. Run the automated test suite using `pytest` to verify your implementation!

## Running Tests
```bash
source venv/bin/activate
pytest tests/
```
