# Valid Substring Split

Given a string and a list of valid words, check if the string can be split into two substrings such that both substrings are valid words in the given list.

### Example: 
Consider the following list:
`l = ["hello", "world", "good", "bye"]`

- `helloworld` can be split into `hello` and `world` and both are valid words. So, the output is `True`.
- `hellogoodbye` can't be split into two valid words. So, the output is `False`.
