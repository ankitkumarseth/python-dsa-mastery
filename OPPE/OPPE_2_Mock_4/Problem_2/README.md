# Most Frequent Element

Given a list of integers, find the integer that occurs most frequently. If there are multiple such integers, return the largest one. Consider that list contains at least one integer.

### Example:
```python
>>> most_frequent_element([1, 2, 3, 4, 5])
5
>>> most_frequent_element([1, 2, 2, 3, 3, 3, 4, 4, 4, 4])
4
>>> most_frequent_element([15, 15, 22, 41, 55])
15
```
