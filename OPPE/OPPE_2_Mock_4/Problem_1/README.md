# Multiple Functions Implementation

Implement all the given functions according to the docstrings. There will be 6 function and 6 testcases corresponding to each of the functions.

1. `second_largest(lst: list) -> int`
2. `arithmetic_operations(t: tuple) -> tuple`
3. `not_present_in_both(lst1: list, lst2: list) -> list`
4. `modify_string_1(s: str) -> str`
5. `create_count_dict(lst1: list, lst2: list) -> dict`
6. `average_of_numbers(lst: list) -> float`
