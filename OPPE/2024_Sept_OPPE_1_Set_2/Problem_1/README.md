# Check Positive Odd or Negative Even

Write a function `is_positive_odd_or_negative_even` that checks if an integer is either a positive odd number or a negative even number. Return `True` if the number meets one of these conditions; otherwise, return `False`.

**NOTE:** This is a function type question, you don't have to take input or print the output, just have to complete the required function definition.

### Examples

**Input:**
```
0
```
**Output:**
```
False
```
*(neither positive nor negative)*

**Input:**
```
3
```
**Output:**
```
True
```
*(positive odd)*

**Input:**
```
-4
```
**Output:**
```
True
```
*(negative even)*

**Input:**
```
4
```
**Output:**
```
False
```
*(positive but even)*

**Input:**
```
-3
```
**Output:**
```
False
```
*(negative but odd)*
