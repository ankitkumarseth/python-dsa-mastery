# Capitalize nth Character

You are given a string `s` and an integer `n`. Your task is to capitalize the nth character in the string `s`. If `n` is greater than or equal to the length of the string, return the string unchanged. (Assuming 0-based indexing as per TCs).

**NOTE:** This is a function type question, you don't have to take input or print the output, just have to complete the required function definition.

### Examples

```python
>>> upper_nth_index_char("hello", 1)
'hEllo'
>>> upper_nth_index_char("python", 3)
'pytHon'
>>> upper_nth_index_char("python", 9)
'python'
```
