# Rotate List

Given a list of items and an integer `k`, rotate the list to the right by `k` steps. Consider that the list contains at least one item.

### Example:
```python
>>> rotate_list([1, 2, 3, 4, 5], 2)
[4, 5, 1, 2, 3]
>>> rotate_list(['a', 'b', 'c', 'd', 'e'], 3)
['c', 'd', 'e', 'a', 'b']
```
