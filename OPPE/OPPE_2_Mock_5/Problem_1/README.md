# Multiple Functions Implementation

Implement all the given functions according to the docstrings. There will be 6 function and 6 testcases corresponding to each of the functions.

1. `squares_of_odds(lst: list) -> list`
2. `pair_elements(t1: tuple, t2: tuple) -> tuple`
3. `modify_string_2(t: tuple) -> str`
4. `unique_vowels(s: str) -> set`
5. `invert_dictionary(input_dict)`
6. `factorial(n: int) -> float`
